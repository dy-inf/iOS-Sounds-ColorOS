# iOS Sounds for ColorOS
[English 🇺🇸](README.md)

Модуль KernelSU Next, который заменяет отдельные системные звуки ColorOS на звуки iOS для более комфортного использования смартфона.

> Модуль создавался для OP15 с ColorOS 17 и KernelSU Next и тестировался только на этом устройстве. **Совместимость с другими устройствами и прошивками не проверялась и не гарантируется.**

## Замененные звуки
| Звук | Файл |
|-|-|
| Блокировка | `Lock.ogg` |
| Разблокировка | `Unlock.ogg` (тишина) |
| Удаление/Очистка | `global_delete.ogg` (тишина) |

## Требования
- Устройство с ColorOS
- KernelSU Next
- Метамодуль *(проверено с Hybrid Mount)*

## Установка
1. Скачать архив из [Releases](../../releases).
2. Открыть KernelSU Next.
3. Установить модуль.
4. Перезагрузить устройство.

Для обновления установите новый архив поверх существующего модуля и перезагрузите устройство.

## Удаление
Удалите модуль в KernelSU Next и перезагрузите устройство.

## Сборка
На Windows запустите `build.bat`
Скрипт создаст `iOS-Sounds-ColorOS.zip`

> Каталог `source-audio` содержит исходные файлы WAV и не включен в архив модуля.
